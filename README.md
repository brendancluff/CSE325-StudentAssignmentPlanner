# Student Assignment Planner

## Project Overview

Student Assignment Planner is a web application designed to help college students organize their school assignments and keep track of deadlines.

This project is being developed using C#, .NET 8, and Blazor as part of the CSE 325 course at BYU-Idaho.

## Planned Features

- Add, edit, and delete classes.
- Create and manage assignments.
- Track assignment due dates.
- Mark assignments as completed.
- View upcoming assignments on a dashboard.

## Target Audience

College students who want a simple way to organize assignments across multiple classes.
